# Login 页面

未登录时的 **Login** 页。登录成功后进入管理端壳（见 [shell.md](./shell.md)）。

API 契约见 [login_api.md](./login_api.md)。

UI 控件统一用 **Element Plus**（经 `shared/ui`）。

| 概念 | 说明 |
|------|------|
| **Login** | 用户名 + 密码（或授权票）→ 会话；需改密时同页完成 |

---

## 主页面

```
+------------------------------------------+
|              Login                       |
|  Username   [ ________________ ]         |
|  Password   [ ________________ ]         |
|  (若需改密 / 票可选)                     |
|  New password [ ______________ ]         |
|  Confirm      [ ______________ ]         |
|                    [ Login ]             |
+------------------------------------------+
```

| 区域 | 说明 |
|------|------|
| 页面标题 | `Login` |
| 表单 | Username、Password；强制改密时 New/Confirm；票模式可选 New password |
| 布局 | 居中卡片；**不**套管理端壳导航 |

| 项 | 说明 |
|----|------|
| 已登录访问本页 | 跳转管理端默认页（或 `redirect`） |
| 未登录访问管理端 | 拦截并跳转本页；成功后回原路由 |

---

## 表单

| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| **Username** | 文本 | 是 | Django `username`；票路径须为超管 |
| **Password** | 密码 | 是 | 普通密码或粘贴 JWT；不明文回显 |
| **New password** | 密码 | 强制改密时必填；票模式可选 | |
| **Confirm** | 密码 | 仅强制改密 | 与 New 一致 |

| 按钮 | 行为 |
|------|------|
| **Login** | `POST /login/`；若 `must_change_password` 则展开改密字段，不进壳；成功则进壳 |

---

## 交互流程

```
打开 Login
  → 密码登录成功且需改密 → 同页填新密码再提交 → 进壳
  → 密码登录成功无需改密 → 进壳
  → Password 为 JWT 且超管票有效 → 进壳（可选同时填新密码重置）
  → 失败 → Toast
```

---

## Toast（建议文案）

| 场景 | 文案 |
|------|------|
| 用户名或密码错误 / 票无效 | `Invalid username or password` |
| 缺字段 | 如表单校验 |
| 需改密 | 提示设置新密码 |
| 登录成功 | 可无 Toast，直接进壳 |
