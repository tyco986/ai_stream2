# Recordings 页面

生产端 Recordings 页面：按流与日期浏览历史录像**文件列表**，支持单文件播放弹窗与下载 / 打包下载。

**组**与**流**的唯一标识均为 **UUID**。树默认展示 **Name**；筛选、选流、日期、API 均以 **id** 为准。

分组树与 [stream.md](./stream.md) 左侧栏同形，本页**只读**（无 ⋮、无增删改）。仅 **`recording: true`** 的流可选中；`recording: false` 灰字，点击仅 Toast，不选中。

左侧栏单列：上 **Groups 树**（可滚动），下 **日期栏**。右侧：顶栏 **Download** + **文件表**（无宫格、无 Preset、无共用时间轴）。

| 区域 | 说明 |
|------|------|
| 页面标题 | 固定 `Recordings` |
| 左侧 · Groups | 只读树 + 标题行图标 + 搜索；上部可滚动 |
| 左侧 · 日期栏 | 底部子栏；当月日历；可选日受**当前选中流**约束 |
| 右侧 · 顶栏 | **Download**（打包勾选文件为 zip；无勾选禁用） |
| 右侧 · 表 | checkbox、文件名、大小、所属流、Operations（下载 / 播放） |

> **无「未分组」节点**；未归属具体组的流等价于 **`All`**。

## 左侧栏（Groups）

### 树

| 节点 | Operations |
|------|------------|
| 组 | 无；key = group id |
| 流 | 无；key = stream id |

流字色**仅看 `recording`**：`true` 可点选；`false` 灰字仅 Toast。

### 选中流

- **单选**一条 `recording: true` 的流；节点旁 `*` 标记当前选中。
- 再点同一流：保持选中（不强制取消；清空用标题行 🧹 或等价清空选中）。
- 换流后：刷新该流当月 **availability**；若当前选中日对该流不可用则清空日与列表。

### Groups 标题行

与 Preview / 旧 Recordings 同形：▦ 筛选、🧹 清空、↻ 刷新树（及当前流日历 / 列表）。

## 日期栏

| 行为 | 说明 |
|------|------|
| 翻月 | `GET /availability?stream_ids={选中流}&month=YYYY-MM` |
| 可选日 | 仅当月返回的有录像日可点；无选中流时全部不可选 |
| 选日 | `GET /files?stream_id=&date=` 刷新右侧表 |

---

## 右侧 · 文件表

| 列 | 说明 |
|----|------|
| checkbox | 勾选参与顶栏 Download |
| Filename | 文件名（basename） |
| Size | 人类可读大小（由 `size_bytes` 格式化） |
| Stream | `stream_name` |
| Operations | **下载**（单文件）、**播放**（弹窗） |

无选中流或未选日：空表（可提示文案）。无分页（按日文件量有限）。

### Download（顶栏）

- 将**当前勾选**行打包为 zip 下载（`POST /download/zip`）。
- 无勾选 → 按钮禁用；空 items → 后端 400。

### 行内下载

- `GET /download?stream_id=&file=`（或等价）→ 单文件 attachment。

---

## 播放弹窗

点击 **播放** 打开对话框（风格对齐 Events Preview 的 prev/next）：

| 区域 | 说明 |
|------|------|
| 信息栏 | 文件名、所属流、起止时刻、大小等 |
| 播放器 | 自定义墙钟时间轴 + `<video>`；`GET /playback` 时间窗；轴内 seek 或换窗；prev/next 换文件 |
| 左右按钮 | prev / next（当前日文件列表内切换）；样式同 Events `preview__nav--prev/next` |
| 滚轮 | 向上 prev、向下 next（加载中忽略） |

首尾文件时对应按钮禁用。切换时重新请求 playback URL 并替换 `video.src`。

## 与其它页关系

| 页 | 关系 |
|----|------|
| Streams | 树数据、`recording` 标志；开录不在本页 |
| Preview | **不**共享布局/预设；本页无宫格 |
| Events | 播放弹窗 prev/next/wheel 视觉与交互对齐；业务无关 |

## 权限

| 权限 | 能力 |
|------|------|
| `recordings.view_recording` | 进页、日历、列表、播放、单文件下载、zip |

无 add/change/delete 写布局类权限需求。
